Spotify Now Playing Widget (black & white) - setup on a new PC

1. Install Python 3.12 (only needed once per machine):

winget install --id Python.Python.3.12

   (type Y if it asks to accept agreements)

2. Double-click start-widget.bat
   First run sets itself up automatically, then starts the server.

   Optional: right-click create-shortcut.ps1 -> Run with PowerShell
   to add a "Spotify Now Playing" icon to your Desktop that launches
   the widget minimized (no console window).

3. In OBS, add a Browser Source pointing to:

http://127.0.0.1:5960/overlay.html

   Set Width to at least 350 and Height to 150. Going narrower than
   350 can clip the right edge of the widget on longer song titles.

Note: this runs on port 5960 (not 5959), so it can run alongside
the Tidal widget at the same time without conflicting.
