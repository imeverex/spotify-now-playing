BLURS SPOTIFY WIDGET - SETUP

1. Double-click "Blurs Spotify Widget.exe"
   If Windows warns about an unrecognized app: "More info" -> "Run anyway"
   It minimizes itself automatically - leave it running while you stream.

2. In OBS: Sources -> + -> Browser -> name it whatever you want
   URL: http://127.0.0.1:5960/overlay.html
   Width: 500, Height: 150 (don't go narrower than 350 wide, or
   long song titles can get their right edge clipped off)

3. Play something in Spotify - the widget shows up in OBS.

To stop it, close the running instance from the taskbar. If it ever
gets stuck, right-click the source in OBS and hit Refresh.
