======================================
 SPOTIFY NOW PLAYING WIDGET - EASY SETUP
======================================

This makes a little box show up in OBS with whatever song is
currently playing in Spotify. Follow these steps in order.


STEP 1: Download the widget
----------------------------
1. Open a web browser (Chrome, Edge, whatever you use)
2. Go to this address:
   https://github.com/imeverex/spotify-now-playing
3. Click the green button that says "Code"
4. Click "Download ZIP"
5. Find the downloaded file (usually in your Downloads folder),
   it will be called "spotify-now-playing-main.zip"
6. Right-click it and choose "Extract All", then click Extract
7. Open the folder that appears


STEP 2: Install Python (one-time only)
----------------------------------------
This widget needs a free program called Python to run.

1. Click the Start button (bottom left of your screen)
2. Type: PowerShell
3. Click "Windows PowerShell" when it shows up. A blue/black text
   window will open, this is where you'll paste the command below.
4. Copy the command: click right before the "w" in "winget" below,
   hold your mouse button down and drag to the end of the line to
   highlight it, then press Ctrl+C on your keyboard to copy it.

   winget install --id Python.Python.3.12

5. Click inside the blue/black PowerShell window so your cursor is
   blinking there
6. Press Ctrl+V to paste it in (if that doesn't work, right-click
   inside the window instead, that also pastes)
7. Press Enter to run it
8. If it asks a question and shows [Y] Yes, type Y and press Enter
9. Wait for it to finish (you'll see your cursor blink on its own
   line again when it's done)
10. Close that window


STEP 3: Start the widget
--------------------------
1. Go back to the folder from Step 1
2. Double-click the file called "start-widget"
   (it may just show a gear/cog icon, that's the right one)
3. If Windows shows a blue box saying "Windows protected your PC":
     - Click "More info"
     - Click "Run anyway"
   (This is normal, it just means the file isn't from the
   Microsoft Store, it's still safe, it's the file you just made)
4. A black window will pop up. The FIRST time you run it, it will
   take a minute or two to set itself up, just let it do its thing.
5. Once it says "Starting Spotify now-playing widget server...",
   it's ready. Leave this black window open the whole time you
   are streaming. If you close it, the widget stops working.


STEP 4: Add it to OBS
------------------------
1. Open OBS
2. Under "Sources", click the + button
3. Click "Browser"
4. Give it any name (like "Spotify Widget") and click OK
5. In the "URL" box, delete whatever is already in there. Then
   either type this exactly, or copy it the same way you did in
   Step 2 (highlight it, Ctrl+C) and paste it in (click the URL
   box first, then Ctrl+V):

   http://127.0.0.1:5960/overlay.html

6. Set Width to 500 and Height to 150
7. Click OK
8. Play a song in Spotify - the widget should appear in OBS
   showing the song title and artist


THAT'S IT
-----------
Every time you want to stream:
 - Open Spotify and play something
 - Double-click "start-widget" again (from the folder in Step 1)
 - Open OBS, the widget source you already added will just work

If the widget ever gets stuck or stops updating, right-click it
in OBS and choose "Refresh".
